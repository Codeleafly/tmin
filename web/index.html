Everything a tunnel needs

Server-authoritative by design: quotas, expiry and ownership are enforced on the server, never on trust.

Permanent named URLs

Your account owns /username forever. Offline routes show a friendly page — they never hand your path to someone else.

Anonymous instant links

One command, no account: a short-lived /a-xxxxxx link. Expiry is owned by the server — reconnects reuse it, never extend it.

OAuth-style CLI login

Device-code flow: approve from your browser, the CLI receives a revocable token. API tokens work everywhere too — CLI, curl, CI.

Quotas & usage

Upload/download accounting per day, visible in the dashboard with progress bars. Exhaustion stops traffic explicitly — never silently.

Admin & audit trail

Bootstrap an admin from env vars, then manage users, quotas, tunnels and maintenance — every privileged action is audit-logged.

Documented REST API

Versioned under /api/v1 with a generated OpenAPI spec. Create tokens in the dashboard and automate everything.

How it works

1

Run your server

One Node process serves the API, WebSocket control plane, gateway and dashboards. TLS via any reverse proxy.

$ npm start
listening on 0.0.0.0:8080
2

Dial out from your machine

The CLI connects out to the server and forwards public traffic to your local app. The server never dials into your network.

$ tmin login
$ tmin http 3000
3

Share the URL

Visitors hit /you on your domain; traffic rides the tunnel back to localhost. Watch it live in the dashboard.

→ {{baseUrl}}/you

Ready when you are

Create an account for permanent URLs — or just run the anonymous command. No sign-up required for instant links.
